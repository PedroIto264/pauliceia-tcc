# Origem do código e atribuição

Este repositório reúne uma adaptação acadêmica de dois projetos do Pauliceia.
A autoria das partes herdadas pertence aos respectivos autores; os READMEs
originais permanecem dentro de cada componente.

| Componente | Repositório de origem | Commit de referência |
| --- | --- | --- |
| Portal | https://github.com/pauliceia/pauliceia | `fc10aeba0d640e83932200b50e18cb9582b2eb2e` |
| API de geocodificação | https://github.com/pauliceia/GeocodingAPI | `b0922690446e97ce66b350b24576ebc98a61df8a` |

As alterações do TCC incluem o experimento em `tcc-local`, recuperação de
candidatos no Elasticsearch, reordenação com Random Forest, endpoints de busca
e de pontos históricos, componente de busca no portal, ambiente Docker local,
testes, documentação, artigo e material de apresentação.

Os dois históricos Git originais continuam nos repositórios de origem. Esta
cópia consolidada inicia um histórico próprio; não contém repositórios aninhados
nem submódulos. Ela não é uma publicação oficial do projeto Pauliceia.

Não foi identificado um arquivo LICENSE na raiz das cópias de origem utilizadas.
Por isso, não foi aplicada uma licença global nova ao código de terceiros.
Avisos existentes nos arquivos foram preservados. A classe IEEEtran fornecida
no template conserva seus próprios avisos. Publicar esta adaptação não deve ser
interpretado como atribuição de autoria exclusiva ou concessão de direitos sobre
todo o material herdado.
